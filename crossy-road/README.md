# Crossy Road

**▶ Play it live:** https://atinm12.github.io/crossy-road/

## What the game is
The game is classic Crossy Road, which is when a user uses left, right, up, down keys to control the chicken's movements, and it dies by hitting a car or falling into the river. My game does not have different characters to choose from, the game items are blurry, and the obstacles do not go faster as you keep going as it does with the normal Crossy Road game.

## How to play
The user can use either arrow keys or wasd controls to move. The user scores by moving across the game map and not getting hit by a car or falling into the river.

## How it was built
I used Claude Sonnet 4.5 and Kiro IDE to build the game. My overall strategy was to build a rough version through one prompt, and then keep iterating through additional prompts where I thought the game was broken or needed improvement.

## Known issues / unfinished
To my knowledge, the unfinished features are the game field not spanning the whole screen, the lack of additional game features such as music, and no prizes.
